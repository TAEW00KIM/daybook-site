ChatGPT, Claude에 연결하기

ChatGPT나 Claude에게 내 Daybook 일정을 묻고, 일정을 만들게 하는 방법

ChatGPT와 Claude(claude.ai)는 Daybook을 커넥터로 연결할 수 있습니다. 연결할 때 브라우저에 8자리 코드가 뜨고, 그 코드를 Daybook 앱에서 승인하면 끝납니다. 비밀번호나 토큰을 따로 복사할 필요가 없습니다.

연결 주소
https://daybook.kimtaewoo.dev/mcp

준비

  • Daybook에 Apple로 로그인되어 있어야 합니다. 로그인 없이 쓰는 경우에는 일정이 기기에만 있어 연결할 수 없습니다.
  • 연결은 컴퓨터 브라우저에서 하는 것이 편합니다. 승인은 iPhone의 Daybook 앱에서 합니다.

ChatGPT

  1. 브라우저에서 chatgpt.com/plugins를 엽니다.
  2. + 단추를 누르고 Add custom MCP server를 고릅니다.
  3. 이름은 Daybook, 연결(Connection) 주소는 위의 연결 주소를 넣고, 인증은 OAuth를 고릅니다.
  4. 안내가 나오면 I understand and want to continue, 이어서 Create as a plugin을 누릅니다.
  5. 브라우저에 8자리 코드가 뜨면 아래 "앱에서 승인하기"로 넘어갑니다.

커스텀 MCP 서버 추가는 ChatGPT 플랜에 따라 보이지 않을 수 있습니다. 메뉴 이름은 ChatGPT 화면이 바뀌면 달라질 수 있습니다.

Claude (claude.ai)

  1. claude.ai에서 설정 > 커넥터를 엽니다.
  2. 커스텀 커넥터 추가를 누르고, 이름은 Daybook, 주소는 위의 연결 주소를 넣고 추가합니다.
  3. 목록의 Daybook에서 연결을 누릅니다.
  4. 브라우저에 8자리 코드가 뜨면 아래 "앱에서 승인하기"로 넘어갑니다.

앱에서 승인하기

  1. iPhone에서 Daybook을 열고 설정 > 에이전트 연결 > 웹 연결 승인 > 코드 입력을 누릅니다.
  2. 브라우저에 뜬 8자리 코드를 넣고 확인을 누릅니다. 코드는 10분 동안 쓸 수 있습니다.
  3. 어느 서비스가 연결하려는지(예: ChatGPT, Claude)와 돌아갈 곳을 확인하고 권한을 고릅니다.
    • 읽기만: 일정과 할 일을 보기만 합니다.
    • 읽고 쓰기: 일정과 할 일을 만들고, 고치고, 지울 수도 있습니다.
  4. 승인을 누르면 브라우저가 저절로 ChatGPT나 Claude로 돌아가 연결이 끝납니다.

직접 시작한 연결이 아니면 승인하지 마세요. 코드를 남에게 보내지 마세요.

연결 끊기

Daybook 앱 설정 > 에이전트 연결 > 연결된 앱에서 밀어서 해제하면 바로 끊깁니다. ChatGPT나 Claude 쪽에서 커넥터를 지워도 됩니다.

알아 두기

  • 연결되면 그 ChatGPT나 Claude 계정을 쓰는 사람은 이 Daybook 계정의 일정을 볼 수 있습니다(읽고 쓰기면 바꿀 수도 있습니다).
  • ChatGPT나 Claude가 가져간 일정은 그 서비스의 방침에 따라 처리됩니다. 자세한 내용은 개인정보 처리방침 3-2를 보세요.
  • Claude Code나 Hermes처럼 토큰을 직접 넣는 에이전트는 에이전트 연결 안내를 보세요.
