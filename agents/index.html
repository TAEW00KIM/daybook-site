에이전트 연결

내 AI 에이전트가 내 Daybook 일정을 읽고 쓰게 하는 방법

Daybook은 MCP(Model Context Protocol) 서버를 제공합니다. Claude Code, Hermes처럼 MCP를 지원하는 에이전트에 주소와 토큰을 넣으면, 에이전트가 내 계정의 일정과 할 일을 보고 만들 수 있습니다. 토큰은 내 계정에만 쓰이고, 다른 사람의 일정에는 닿지 않습니다.

ChatGPT나 Claude(claude.ai)에 연결하려면 토큰 대신 앱에서 승인하는 방식이 더 간단합니다: ChatGPT, Claude에 연결하기.

Apple로 로그인한 경우에만 쓸 수 있습니다. 로그인 없이 쓰는 경우에는 일정이 기기에만 있어 연결할 서버가 없습니다.

1. 토큰 만들기

  1. Daybook 앱에서 설정 → 에이전트 연결을 엽니다.
  2. 새 토큰 만들기를 누르고 이름(예: claude-code)과 권한을 고릅니다.
    • 읽기만: 일정을 보고 찾기만 합니다.
    • 읽고 쓰기: 일정과 할 일을 만들고 고치고 지울 수 있습니다.
  3. 만든 직후 화면에서 MCP 주소와 토큰을 복사합니다. 토큰은 이 화면을 닫으면 다시 볼 수 없습니다. 잃어버리면 폐기하고 새로 만드세요.

2. Claude Code

터미널에서 한 줄로 추가합니다. 앱의 결과 화면에 이 명령이 그대로 복사되는 단추가 있습니다.

claude mcp add --transport http daybook <MCP 주소> \
  --header "Authorization: Bearer <토큰>"

추가한 뒤 Claude Code에서 "오늘 일정 알려 줘"처럼 물어보면 됩니다.

3. Hermes

프로필의 config.yaml에 mcp_servers 항목을 더합니다. 토큰은 파일에 직접 쓰기보다 환경 변수로 두는 것을 권합니다.

mcp_servers:
  daybook:
    url: "<MCP 주소>"
    headers:
      Authorization: "Bearer ${DAYBOOK_MCP_TOKEN}"
    timeout: 60
    connect_timeout: 10

4. 그 밖의 에이전트

원격 MCP 서버(Streamable HTTP)를 지원하는 에이전트라면 같은 방식으로 연결합니다. 설정에 다음 두 가지를 넣으세요.

  • 주소: 앱에 보이는 MCP 주소(끝이 /mcp)
  • 헤더: Authorization: Bearer <토큰>

설정 형식은 에이전트마다 다르니 그 에이전트의 MCP 설명서를 따르세요.

5. 할 수 있는 일

  • 오늘 날짜와 시간대 확인, 일정과 할 일 목록 보기, 검색, 빈 시간 찾기, 구독 결제 보기
  • 읽고 쓰기 토큰이면: 일정과 할 일 만들기, 고치기, 완료, 지우기, 잘못 바꾼 것 되돌리기

에이전트가 바꾼 내용은 변경 기록에 토큰 이름과 함께 남고, 앱에서 바로 보입니다.

6. 한도와 보안

  • 토큰은 계정마다 10개까지 만들 수 있습니다.
  • 토큰마다 호출은 1분에 120번, 쓰기는 1분에 60건까지입니다. 넘으면 잠시 뒤에 다시 시도하라는 응답이 옵니다.
  • 토큰은 비밀번호처럼 다루세요. 남에게 보이지 않게 하고, 쓰지 않거나 노출된 것 같으면 설정 → 에이전트 연결에서 바로 폐기하세요. 폐기하면 즉시 막힙니다.
  • 에이전트에게 넘긴 일정은 그 에이전트(와 그 에이전트가 쓰는 AI 서비스)가 처리합니다. 자세한 내용은 개인정보 처리방침 3-2를 보세요.
  • 다른 사람에게 공유받은 일정은 에이전트에 보이지 않습니다(목록, 검색, 빈 시간 찾기 모두).
